# Region and Innkeeper
Working draft for the first playable region. ESTABLISHED = agreed foundation; PROVISIONAL = may change; OPEN = undecided. Do not treat provisional details as immutable canon. Godwin is the current innkeeper name; no surname has been assigned. Naming customs and religion are intentionally not fully defined yet.

## Two layers of lore (for AI chat)
1. **World bible (git)** — Markdown in this folder and `Rosiegame_AI_World_Bible/`. Human-edited baseline the server loads on every reply.
2. **Established canon (MongoDB or local `data/npc-canon.json`)** — Short facts the game decides are now true after NPC conversations. The AI must stay consistent with these in later talks. Edit git files when you want to promote something to official bible text.
