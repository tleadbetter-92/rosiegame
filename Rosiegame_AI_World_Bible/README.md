# Rosiegame AI World Bible

A working pack for the AI Dungeon Master. This is not all final canon.

**Status labels**
- ESTABLISHED: agreed foundation.
- PROVISIONAL: considered, but not final.
- EXAMPLE ONLY: illustrative story/NPC, not automatically canon.
- OPEN QUESTION: deliberately unresolved.

Read `00_AI_RULES/AI_WORLD_RULES.md` first. Do not promote examples or provisional ideas to canon silently. Update the relevant file when decisions change; move superseded material to `99_ARCHIVE/`.

**In the live game:** baseline text comes from git on the server; **play-established facts** accumulate in MongoDB (same database as campaign/messenger when `MONGODB_URI` is set) or in gitignored `data/npc-canon.json` locally. Promote stable facts into markdown here when you are happy with them.
