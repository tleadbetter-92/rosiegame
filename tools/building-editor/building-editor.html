Building editor

2 m grid — one rule for all kit pieces: click snaps the tile centre (same anchor as Floor_Brick). No extra nudge — balconies, overhangs, walls, and floors share that point; rotate with R so “outward” faces the edge you want. Q/E storey.

Floors & props (megakit)
  • Floor — Floor_Brick, Floor_RedBrick, Floor_UnevenBrick, Floor_WoodDark / Floor_WoodLight (+ half tiles & overhang corners).
  • Prop — crates, wagon, chimneys, vines, fences, border trim; search prop or floor above.
  • Medieval street lamps are not in this kit — use the town editor lamp or add CC0 models under models/town-props/ (see README there).
How to roof (megakit)
  1. Q/E to the top floor (same footprint as walls).
  2. Roof → Roof RoundTiles N×M — same cell-centre snap as floors; size name ≈ metres (4×4 ≈ 4 m).
  3. Overhang — same tile-centre click as floors; long pieces extend ~2 m along +Z at rotation 0.
  4. Roof → Roof Front Brick4/6/8 — gable end; rotate to face the end wall.
  5. Corner / Wall / Window / Door — all anchor on square centres like Floor; rotate with R.

Floor level: 1 (y = 0)
